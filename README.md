# 🧠 Projetos de Estruturas de Dados I

📚 Repositório criado para reunir projetos e exercícios desenvolvidos durante
os estudos da disciplina de **Estruturas de Dados I**.

Aqui estão organizadas diferentes implementações envolvendo **listas, filas,
pilhas, árvores, recursividade, ordenação e manipulação de dados**, com foco
na prática dos conceitos fundamentais de estruturas de dados.

---

## 📂 Projetos

### 🌳 Árvore Binária
Implementação e manipulação de uma estrutura de **árvore binária**,
explorando a organização hierárquica dos dados.

### 👥 Cadastro de Clientes
Projeto voltado para o armazenamento, organização e manipulação de
informações de clientes utilizando estruturas de dados.

### 🔤 Contador de Palavras
Programa desenvolvido para realizar a contagem e manipulação de palavras,
trabalhando com processamento e organização de dados.

### 🔄 Conversão de Base
Exercício envolvendo conversão de números entre diferentes bases,
aplicando conceitos de manipulação de dados e estruturas auxiliares.

### 🔗 Lista Duplamente Encadeada
Implementação de uma **lista duplamente encadeada**, permitindo navegação
e manipulação dos elementos nos dois sentidos.

### ♻️ Lista Recursiva
Projeto desenvolvido para praticar a utilização de **recursividade**
na manipulação de uma estrutura de dados.

### 🏎️ Lista Simples de Pilotos
Implementação de uma lista encadeada para organização e manipulação
de informações relacionadas a pilotos.

### 👀 Lista Simples Visual
Projeto voltado à visualização e manipulação de uma **lista simplesmente
encadeada**, facilitando a compreensão do funcionamento da estrutura.

### 📍 Objetos e Ponteiros
Exercícios envolvendo a utilização de **objetos e ponteiros**, reforçando
conceitos de memória e manipulação de dados.

### 🔀 Ordenação de Fila
Implementação de técnicas para organizar os elementos de uma **fila**
de acordo com uma determinada ordem.

### 📚 Ordenação de Pilha
Projeto envolvendo a ordenação dos elementos de uma **pilha**, aplicando
operações sobre a estrutura para reorganizar seus dados.

### 🔁 Recursividade
Exercícios dedicados à prática de **funções recursivas** e à resolução
de problemas utilizando esse conceito.

## 🎯 Objetivo

O objetivo deste repositório é registrar a evolução prática no estudo de
**Estruturas de Dados I**, reunindo diferentes projetos para desenvolver
uma compreensão mais sólida sobre organização, armazenamento, acesso e
manipulação de dados.

📈 Cada projeto representa uma etapa diferente do aprendizado e da aplicação
dos conceitos estudados.

Este projeto faz parte da minha formação em **Engenharia da Computação**
e reúne diferentes implementações desenvolvidas ao longo dos estudos.

💡 A ideia é utilizar esses projetos não apenas como exercícios acadêmicos,
